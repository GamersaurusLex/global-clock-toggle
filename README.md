# Global Clock Toggle

A Foundry VTT v14 companion for Global Progress Clocks. Each user can show or hide every clock on their own client with the Token Controls eye button, a client setting, or the configurable `Ctrl+Shift+G` keybinding.

## Changelog

### 0.1.0

- Initial release.
- Adds a per-user Token Controls button and configurable keybinding for showing or hiding Global Progress Clocks.
